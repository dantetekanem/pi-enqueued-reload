# pi-enqueued-reload

Type `/reload` anytime. Pi finishes its work, then reloads once, even if you ask again.

```sh
pi install npm:pi-enqueued-reload
```

After installing, run `/reload` when Pi isn't busy. If another editor extension blocks it, use `/pi-enqueued-reload`.

Tested with Pi 0.85.1. [Changes](CHANGELOG.md) · [MIT license](LICENSE).
